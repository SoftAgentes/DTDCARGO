# LB-SGE-104 · Baseline de cobertura de gobernanza v1

Fecha: 2026-07-31

Supersede: [LB-SGE-103](BASELINE-2026-07-31-08.md)

## Decisión

Se registra la primera fotografía completa de cobertura para los módulos
canónicos de Studio:

- `lib/studio/modules.ts` contiene 57 módulos, no 55;
- 22 módulos poseen evidencia durable de al menos un flujo acotado;
- 27 módulos activos R2/R3 conservan una brecha de evidencia integral;
- ocho módulos son read-only o placeholders: las políticas de mutación pueden
  ser `no aplica`, pero A11Y-01 y VIS-01 todavía necesitan evidencia runtime;
- no apareció una excepción formal nueva ni una no conformidad de código que
  pueda probarse únicamente con el barrido estático.

La baseline no reabre Gobernanzas 1–8, no modifica políticas y no convierte un
flujo verificado en conformidad automática de todo el módulo.

## Evidencia

- base auditada: `origin/main` `1103ccdec4949687c29d20ed22dc742e2f4c9b19`;
- fuente canónica de módulos: `lib/studio/modules.ts`;
- fuente normativa: `docs/governance/README.md`;
- plugin validado como read-only con 27 políticas y cuatro componentes;
- matriz completa por cinco superficies y 57 módulos en REV-SGE-029.

## Fronteras preservadas

- cero cambios de producto, políticas, cápsula o registry derivado;
- cero Cloud, Auth, Producción, Vercel, migraciones o limpieza;
- la evidencia runtime autenticada permanece pendiente;
- la adopción continúa únicamente por slices R2/R3 con SDD y allowlist exacta;
- LB-SGE-103 conserva el recibo productivo de Gobernanza 8;
- ningún lote E5 fue creado ni ejecutado por esta revisión.
