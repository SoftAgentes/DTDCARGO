# Revisión normativa de CMP-01

| Control | Valor |
|---|---|
| Revisión | REV-SGE-006 |
| Política | [CMP-01 v1.0](../policies/cmp-01.md) |
| Fecha | 2026-07-29 |
| Resultado | aprobada |

CMP-01 distingue experimental, proposed, canonical, deprecated y retired;
exige evidencia de accesibilidad, pruebas, consumidores y reemplazo. Crear un
componente no lo vuelve canónico.

La aprobación establece el contrato normativo. El catálogo ejecutable y la
auditoría de componentes permanecen pendientes. PLG-01 no fue aprobado en este
gate.
