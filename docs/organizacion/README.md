## Reglas de esta carpeta

- **Personas, solo por nombre de pila.** La fuente de quién ocupa cada puesto es el ERP
  (`nomina_positions`, Studio › Nómina). Aquí solo van propuestas con nombres de pila que ya
  están en el repositorio. Nada de correos, teléfonos, sueldos ni datos de empleados.
- Los gráficos van en `assets/`.
- **Montos fuera de Git.** Presupuestos sugeridos sí; sueldos, saldos o costos reales no.
- Lo que se apruebe aquí y cambie reglas del repositorio o de gobierno pasa por una SDD
  (`docs/specs/`) con número asignado por el Director.
