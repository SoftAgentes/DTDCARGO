# Carrusel maestro · capacidad operativa

Plantilla maestra de seis láminas del **Sistema Editorial Técnico DTD Cargo**,
aprobada como base estructural para carruseles educativos.

## Tema del piloto

Capacidad operativa de contenedores:

- 20GP: hasta ~28 CBM.
- 40HQ: hasta ~68 CBM.

La comunicación diferencia capacidad operativa de volumen nominal y evita
publicar dimensiones que no ayudan a la decisión del cliente.

## Arquitectura reutilizable

1. Gancho o pregunta principal.
2. Concepto que elimina una confusión.
3. Comparación directa.
4. Ficha de la primera opción.
5. Ficha de la segunda opción.
6. Decisión guiada y CTA.

## Archivos

- `carousel.html`: fuente editable, 1080 × 1350 px por lámina.
- `overview.html`: vista de control de las seis láminas.
- `PROMPTS.md`: prompts reproducibles de las fotografías técnicas.
- `assets/contenedores-20gp-40hq-studio.png`: fotografía técnica generada para
  la plantilla.
- `assets/contenedor-20gp-studio.png`: fotografía individual para la ficha 20GP.
- `assets/contenedor-40hq-studio.png`: fotografía individual para la ficha 40HQ.
- `assets/contenedor-20gp-banner.png`: encuadre horizontal final de la ficha 20GP.
- `assets/contenedor-40hq-banner.png`: encuadre horizontal final de la ficha 40HQ.
- `exports/01-portada.png` a `exports/06-cta.png`: entregables listos para
  revisión y publicación.
- `exports/00-vista-general.png`: hoja de contacto para revisión rápida.

## Reglas de reutilización

- Mantener una sola idea principal por lámina.
- Conservar Archivo Black, Archivo y JetBrains Mono.
- Usar sólo la paleta oficial navy, vino y papel.
- Escribir siempre `DTD Cargo`; nunca `DTDCARGO` ni `DTD CARGO` como wordmark.
- Verificar cifras y fuente antes de exportar.
- Mantener el CTA vinculado a una ruta real de `dtdcargo.com`.
- No publicar sin revisión visual, ortográfica y técnica.
