# Fotografías editoriales generadas · lote V1

depender de imágenes históricas con personas, uniformes, logos, QR, URLs,
credenciales o pantallas que requieran permisos o retoques adicionales.

## Reglas de uso

- Son material editorial generado; no representan empleados, clientes,
  proveedores, instalaciones ni operaciones documentales reales de DTD Cargo.
- Los textos, logos y Shipping Marks se añaden en la plantilla, nunca dentro de
  la fotografía generada.
- No contienen marcas de terceros, QR, URL, credenciales ni pantallas legibles.
- Las fotografías 01 y 07 contienen presencia humana genérica; no requieren
  cesión de una persona real.
- Los originales de alta resolución permanecen fuera del repositorio. Estas
  copias JPEG optimizadas pesan menos de 1 MB cada una.
