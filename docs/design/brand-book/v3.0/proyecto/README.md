## Cómo abrir

1. Descomprimí el ZIP
2. Abrí `Brand Book DTD v3.0.html` con cualquier navegador moderno
3. Las 5 secciones externas (Logo Oficial, Íconos, Aplicaciones) están vinculadas
4. Imprimí desde el navegador (Ctrl+P / Cmd+P) para PDF

## Para Cloud Code

Pasos sugeridos al integrar al codebase:
1. Leer CLAUDE.md y BRAND-MIGRATION-2026-05.md
2. Reemplazar todos los `dtdcargo-icon-navy.png` por la variante adecuada de las 4 nuevas
3. Reemplazar `DTDCARGO` (una palabra) por el componente Lockup (DTD + 0.15em + Cargo)
4. Verificar con los grep del paso final de BRAND-MIGRATION
