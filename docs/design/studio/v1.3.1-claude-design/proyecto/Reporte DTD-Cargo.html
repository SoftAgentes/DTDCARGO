Reglas que Claude Code debe respetar. Si el usuario pide algo fuera de estas reglas, debe avisar con el formato BRAND-CHECK.

Tipografía

  • Archivo Black — títulos display, KPIs, encabezados
  • Archivo regular — body, labels, buttons
  • JetBrains Mono — códigos: MARKBOX DTD-XXXX, DTDU-XXXXXX, F-2026-XXXX, fechas en tablas
  • Noto Sans SC — chino mandarín (direcciones de almacén CN)
Fuentes prohibidas: Inter, Roboto, Open Sans, Lato, Montserrat, Helvetica, Arial — son AI slop.

AI Slop · prohibido absolutamente

  • ❌ Gradientes coloridos (rosa-naranja, púrpura, "vaporwave")
  • ❌ Cards con border-left random
  • ❌ Iconos circulares con emoji decorativo
  • ❌ Bordes redondeados de 24px+ en todo
  • ❌ Glassmorphism / acrylic blur
  • ❌ Texto centrado por defecto
  • ❌ "Made with ❤️", "Powered by AI"
  • ❌ Dashboards con barras de colores aleatorios

5 reglas que NO se rompen

  1. Solo tokens CSS (var(--*)). Cero hex inventados.
  2. Solo fuentes Archivo + JetBrains Mono + Noto Sans SC. Nada más.
  3. Cero AI slop: sin gradientes coloridos, sin emojis decorativos, sin glassmorphism.
  4. Componentes del sistema primero. Inventar solo con /* TODO: brand-review */.
  5. Avisar antes de violar. Formato BRAND-CHECK explícito.

Stack técnico

  • React 18.3.1 + JSX inline · cargado vía Babel standalone
  • Inline styles con tokens CSS · sin Tailwind, sin styled-components
  • Sin build step · cada HTML carga directo en el navegador
  • Mock data en erp/data.jsx expuesto vía window.ERPData
  • Componentes compartidos expuestos en window.ERPUI e window.Icon
  • Mobile usan los mismos tokens · viewport-fit cover · safe-area-inset
