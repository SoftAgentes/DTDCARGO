  patrón de la #149 y la #152:
  - `dblink` contra una base propia;
  - barrera por `pg_blocking_pids`, sin `sleep`;
  - limpieza protegida ante cualquier error;
  - guarda de clúster desechable.
- **Fixture:** el de cada contrato, leído de su archivo con un intérprete mínimo de psql. Reemplaza
  cada `\ir` por la migración que incluye, resuelve `\if :var` / `\else` / `\endif` con valores
  fijos y aborta ante cualquier otro meta-comando. Así va la 0421 en modo `fixture_only`, más la
  0464, y la 0427 en modo `keep_fixture`. Si un contrato cambia de forma, el test falla con un
  mensaje que lo nombra, en vez de probar sobre otro fixture.
- **`supabase/tests/0421_comandos_pago_carrera.test.sql`** (17 aserciones), sobre la función que
  queda en producción, la 0421 con la 0464 encima:
  1. Último cupo: con cuatro pendientes, de dos altas simultáneas una entra y la otra recibe
     `PAYMENT_PENDING_LIMIT`. Quedan cinco pendientes y cinco recibos.
  2. La misma solicitud dos veces: la segunda espera en el **advisory lock** y reproduce la
     primera, con el mismo `audit_event_id`. Queda un solo evento.
  3. La misma solicitud con otros datos, sobre otra factura: la segunda espera en el advisory lock
     y recibe `PAYMENT_REQUEST_CONFLICT`, sin crear nada. Este caso es el que mata al mutante sin
     advisory lock: sin él, el choque sale como clave duplicada cruda.
  4. Revocación del Portal en curso: el alta espera y recibe `PAYMENT_FORBIDDEN`, sin reporte.
  5. Baja financiera en curso: la resolución espera y recibe `PAYMENT_FORBIDDEN`, y el reporte
     sigue `reportado`.

- **`supabase/tests/0427_borrado_direccion_carrera.test.sql`** (23 aserciones), con los ocho

  1. doble borrado: un solo evento;
  2. doble borrado con el primero revertido: el segundo borra;
  3. revocación en curso: el borrado espera y devuelve false;
  4. traslado de la dirección a otro cliente: false, sin borrarla;
  5. baja del cliente: false;
  6. dirección tomada más de 2 s: corta con lock timeout;
  7. snapshot `REPEATABLE READ` viejo: 40001;

## Control rojo reproducible (fuera del repo)

Los mutantes no viven en el repo. Este script arma en una carpeta nueva una copia de
`supabase/migrations`, del contrato del que sale el fixture y del test de la carrera, con **una**
mutación de bloqueo, y la pasa por el runner real:

```bash
node rojo-0421-0427.cjs "<worktree>" "<carpeta-nueva-fuera-del-repo>" <variante>
```

Variantes: `factura`, `solicitud`, `vinculo`, `membresia` y `verde0421`, para la 0421 (mutada en la
0464); `direccion`, `vinculo27`, `cliente27`, `timeout27` y `verde0427`, para la 0427.

```js
// Control rojo de los tests de carrera de la 0421 y la 0427, fuera del repo.
// Arma una copia de supabase/ (migraciones + el contrato del que sale el
// fixture + el test de la carrera) con UNA mutación de bloqueo y la pasa por el
// runner real (scripts/run-sql-tests.mjs). El contrato también corre, porque
// el runner corre todo *.test.sql.
//
//   node rojo-0421-0427.cjs <worktree> <carpeta-nueva> <variante>
//
// Variantes de la 0421 (se mutan en la 0464, que instala la función que queda
// en producción; su postflight compara el md5 del cuerpo, así que en la copia
// esa comparación se neutraliza, y el diff lo muestra):
//   factura    el alta sin el FOR UPDATE de la factura           → ✗
//   solicitud  sin el advisory lock por request_id               → ✗
//   vinculo    el alta sin el FOR SHARE del vínculo del Portal   → ✗
//   membresia  la resolución sin el FOR SHARE de user_tenants    → ✗
//   verde0421  sin mutación                                      → ✓
// Variantes de la 0427:
//   direccion  sin el FOR UPDATE de la dirección                 → ✗
//   vinculo27  sin el FOR SHARE del vínculo del Portal           → ✗
//   cliente27  sin el FOR SHARE del cliente                      → ✗
//   timeout27  sin el lock_timeout de 2 s de la función          → ✗
//   verde0427  sin mutación                                      → ✓
const fs = require("node:fs");
const path = require("node:path");
const { spawnSync } = require("node:child_process");

const [W, D, V] = process.argv.slice(2);
if (!W || !D || !V) throw new Error("uso: node rojo-0421-0427.cjs <worktree> <carpeta-nueva> <variante>");
fs.mkdirSync(D); // falla si ya existe: nunca se reutiliza ni se borra nada
fs.mkdirSync(path.join(D, "supabase", "tests"), { recursive: true });
fs.cpSync(path.join(W, "supabase", "migrations"), path.join(D, "supabase", "migrations"), { recursive: true });

const es0421 = ["factura", "solicitud", "vinculo", "membresia", "verde0421"].includes(V);
const es0427 = ["direccion", "vinculo27", "cliente27", "timeout27", "verde0427"].includes(V);
if (!es0421 && !es0427) throw new Error("variante desconocida: " + V);
const tests = es0421
  ? ["0421_payment_report_commands.test.sql", "0421_comandos_pago_carrera.test.sql"]
  : ["0427_portal_delete_delivery_address_command.test.sql", "0427_borrado_direccion_carrera.test.sql"];
for (const t of tests) fs.copyFileSync(path.join(W, "supabase", "tests", t), path.join(D, "supabase", "tests", t));

const archivo = es0421 ? "0464_reporte_pago_factura_pagada.sql" : "0427_portal_delete_delivery_address_command.sql";
const destino = path.join(D, "supabase", "migrations", archivo);
let s = fs.readFileSync(destino, "utf8");
const una = (a, b) => {
  const n = s.split(a).length - 1;
  if (n !== 1) throw new Error(`«${a.slice(0, 60)}» aparece ${n} veces en ${archivo}`);
  s = s.replace(a, b);
};
const md5 = "      and pg_catalog.md5(prosrc) = 'c3aab7fcb10e3bf5de0fa40cc562a45d') then";
switch (V) {
  case "factura":
    una("and client_markbox = v_markbox\n    for update;\n  else", "and client_markbox = v_markbox;\n  else");
    una(md5, "      and true) then");
    break;
  case "solicitud":
    una("  perform pg_catalog.pg_advisory_xact_lock(pg_catalog.hashtextextended('payment-command:' || p_request_id::text, 0));\n", "");
    una(md5, "      and true) then");
    break;
  case "vinculo":
    una("c.deleted_at is null\n    for share of cu, c;", "c.deleted_at is null;");
    una(md5, "      and true) then");
    break;
  case "membresia":
    una("ut.role in ('admin', 'accounting')\n    for share;", "ut.role in ('admin', 'accounting');");
    una(md5, "      and true) then");
    break;
  case "direccion":
    una("a.client_markbox=v_markbox\n  for update;", "a.client_markbox=v_markbox;");
    break;
  case "vinculo27":
    una("cu.status='active'\n  for share;", "cu.status='active';");
    break;
  case "cliente27":
    una("c.deleted_at is null\n  for share;", "c.deleted_at is null;");
    break;
  case "timeout27":
    una("set search_path = ''\nset lock_timeout = '2s'\nas $function$", "set search_path = ''\nas $function$");
    break;
}
fs.writeFileSync(destino, s);

const diff = spawnSync("git", ["diff", "--no-index", "--unified=0", "--no-color",
  path.join(W, "supabase", "migrations", archivo), destino], { encoding: "utf8" });
console.log(`== diff de ${archivo} (${V}):`);
console.log(diff.stdout.split("\n").filter((l) => /^[-+][^-+]/.test(l) || /^@@/.test(l)).join("\n") || "(sin cambios)");

const t0 = Date.now();
const run = spawnSync(process.execPath, [path.join(W, "scripts", "run-sql-tests.mjs")], { cwd: D, encoding: "utf8" });
process.stdout.write((run.stdout || "") + (run.stderr || ""));
console.log(`== runner exit ${run.status} en ${Date.now() - t0} ms`);
process.exitCode = run.status;
```
